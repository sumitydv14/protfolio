## 🚀 **Getting Started**

### **1. Start Development Server**
```bash
cd c:\Users\siwani\Desktop\PORTFOIO
npm run dev
```
→ Open http://localhost:3000 in browser

### **2. Customize Content** (5 minutes)
Edit these files:
- `src/data/projects.ts` - Add your projects
- `src/data/skills.ts` - Update skills
- `src/data/experience.ts` - Update experience
- `src/data/navigation.ts` - Update social links

### **3. Customize Colors** (Optional, 1 minute)
Edit `tailwind.config.ts` to change colors

### **4. Build for Production**
```bash
npm run build
```
→ Static files in `out/` directory

### **5. Deploy**
- **Vercel**: Push to GitHub + import to Vercel
- **Netlify**: Deploy `out/` folder
- **GitHub Pages**: Deploy `out/` folder to gh-pages
